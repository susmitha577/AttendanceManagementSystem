# Attendance Management System

## 📌 Project Description

The Attendance Management System is a web-based application developed to manage student attendance efficiently.

It allows administrators to manage students, departments, courses, faculty, and attendance records through a centralized system.

## 🛠️ Technologies Used

- HTML
- CSS
- JSP
- Java
- Apache Tomcat
- MySQL

## ✨ Features

- Administrator Login
- Admin Dashboard
- Student Management
- Faculty Management
- Department Management
- Course Management
- Regulation Management
- Attendance Management
- Attendance Records
- Password Change
- Attendance Success/Status

## 🗄️ Database

MySQL is used as the database for storing:

- Student details
- Faculty details
- Department details
- Course details
- Attendance records
- Administrator details

## 🚀 How to Run

1. Install Java JDK.
2. Install Apache Tomcat.
3. Install MySQL Server.
4. Create the required MySQL database.
5. Configure the database connection in the project.
6. Copy the project files into the Tomcat `webapps` folder.
7. Start Apache Tomcat.
8. Open the application in a web browser.
